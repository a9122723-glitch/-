# 젓가락 탐험대 v0.2.0 — 젓가락 끝/음식 동반이동 판정 MVP

## 무엇이 바뀌었나요?
- 기존 아이폰 후면 카메라 및 MediaPipe Hand Landmarker 구조 유지 (현재 사용자 환경에서 사용 중인 `@mediapipe/tasks-vision@1.2.3`).
- **마커 3색을 구분**: 음식 빨강, 젓가락 A 끝 파랑, 젓가락 B 끝 노랑.
- 각 색상을 픽셀 평균이 아닌 **연결된 색상 영역 중 큰 영역**으로 검출.
- 두 젓가락 끝이 음식 중심의 양쪽에서 가까워지고, 적절한 간격을 유지할 때 **집기 후보** 판정.
- 음식과 젓가락 끝의 중앙점이 **같은 방향으로 여러 영상 프레임에서 이동**할 때 운반 후보 확인.
- 음식을 목표 영역에 위치시키고 양쪽 끝이 떨어져 **음식이 안정적으로 정지**할 때 별 10점 지급.
- 손 관절 추적을 계속 표시하며 엄지·검지 간격 정보를 보조 피드백으로 표시.
- 단계별 상태와 AI 오류 진단 기록 지원.

## 설치/배포
1. `index.html`을 GitHub 저장소의 최상위 경로에 업로드합니다. 현재 정상 작동 중인 v0.1.4의 백업을 먼저 만드세요.
2. GitHub Pages를 활성화하고 `https://<사용자>.github.io/<저장소>/` 주소로 접속합니다.
3. iPhone Safari에서 주소에 `?v=020`을 붙여 새 버전인지 확인합니다. **파일 앱에서 직접 열면 안 됩니다.**
4. 상단에 v0.2.0이 표시되어야 합니다.

## 준비물
- 스마트폰 상단 거치대 (후면 카메라를 무광 놀이 매트에 수직으로 고정).
- **검정 또는 회색 무광 매트** (초록/노랑/파랑/빨강 배경 피하기).
- 빨간색 마커가 붙은 음식 장난감 1개.
- 젓가락 끝 근처에 파랑·노랑 테이프를 각각 감은 젓가락 한 쌍. 테이프는 분리·삼킴 위험이 없게 단단히 고정하고 보호자가 감독해야 합니다.
- 충분하고 고른 조명. 색상 인식이 불안정하면 조명과 마커 크기를 조절하세요.

## 게임 시나리오
1. 시작 영역(왼쪽)에 빨간 음식 장난감을 놓습니다.
2. 손과 세 가지 색상 마커가 모두 화면에 보이도록 합니다.
3. 젓가락 양끝이 음식 양쪽에 접근하며 집기 후보가 5회 연속 관측되면 `집기 후보`가 됩니다.
4. 음식과 양 젓가락 끝이 같은 방향으로 움직이고, 음식이 출발점에서 충분히 이동하면 `운반 확인`이 됩니다.
5. 오른쪽 목표 영역에 도착해 젓가락을 벌리고, 음식이 약 0.6초 안정적으로 보이면 별 10점입니다.

## 기술적 한계와 계획
- 이 MVP는 RGB 색상 마커와 단일 상단 카메라를 사용합니다. 영상 속 위치 관계는 **실제 접촉·악력·수직 들어 올리기의 증거가 아닙니다.** 단독 사용으로 올바른 젓가락질을 인증할 수 없습니다.
- 손가락 간격은 참고용이며, 정식 자세 점수 또는 의료/교육 평가를 제공하지 않습니다.
- 3색 테이프 위치는 젓가락 끝에서 비슷한 거리로 맞춰야 합니다. 마커가 너무 멀면 접촉 판정에 오차가 생깁니다.
- 다음 단계: 젓가락의 전체 선분과 끝점을 검출하는 커스텀 모델, 음식을 인스턴스 분할하는 모델, 측면 카메라/깊이 단서, 실제 어린이 영상 기반 정밀도·재현율 검증, 전문가 검토.
- MediaPipe 모델 및 JS/WASM은 외부 서버에서 다운로드합니다. 카메라 영상은 사용자 브라우저 내부에서 처리하며 이 코드에는 업로드 기능이 없습니다.

## 문제가 생기면
- AI가 작동하지 않으면 진단 기록을 복사합니다.
- 3색 마커가 감지되지 않으면 화면의 `젓가락 끝 A/B`와 `음식 인식` 메시지를 확인합니다. 배경을 무채색으로 바꾸고 조명을 조정하세요.
- 페이지가 v0.2.0으로 바뀌지 않았으면 GitHub에 `index.html`이 실제 교체되었는지 확인하세요.
